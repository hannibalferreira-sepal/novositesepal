# Links do site SEPAL

Troque `SEU-DOMINIO` pelo endereço da Vercel (ex.: novositesepal.vercel.app).

| Página | Arquivo | Link |
|---|---|---|
| Home (site principal) | index.html | https://SEU-DOMINIO/ |
| Área Missionária (Central) | area-missionaria.html | https://SEU-DOMINIO/area-missionaria.html |
| Health Score (Painel Vínculo) | painel-vinculo.html | https://SEU-DOMINIO/painel-vinculo.html |

## Como as páginas se conectam
- Home > menu "Área Missionária" > area-missionaria.html
- Área Missionária > "Site SEPAL" > index.html
- Área Missionária > perfil Administrador > botão "Health Score" > painel-vinculo.html
- Painel Vínculo > "← Área Missionária" > area-missionaria.html

## Para o link externo dos CS (futuro)
Use o link do Health Score: https://SEU-DOMINIO/painel-vinculo.html
Quando houver login, ele passa a ficar protegido.
